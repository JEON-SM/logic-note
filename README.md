# Logic Note

도형과 선으로 생각을 잇는 개인용 노트. 브라우저에서 돌아가고, Windows·갤럭시 기기에 앱처럼 설치할 수 있습니다(PWA). 화면은 **한국어·English** 두 가지입니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 정적 파일 생성
```

`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 빌드해서 GitHub Pages에 올립니다. 저장소의 **Settings › Secrets and variables › Actions › Variables**에 `GOOGLE_CLIENT_ID`를 넣어 두면 그 클라이언트 ID가 앱에 내장되어, 기기마다 입력할 필요가 없습니다.

올린 주소를 Edge/Chrome에서 열고 주소창의 **앱 설치**를 누르면 Windows 앱으로, 갤럭시의 Chrome·삼성 인터넷에서 **홈 화면에 추가**하면 휴대폰/태블릿 앱으로 쓸 수 있습니다. 설치 후에는 오프라인에서도 열립니다.

### Windows 실행 파일 (.exe)

`desktop/`에 작은 실행기가 있습니다. 더블클릭하면 Logic Note를 Chrome(없으면 Edge)의 독립된 앱 창으로 엽니다. 브라우저 안에서 열리므로 Google 로그인·Drive 동기화·오프라인이 그대로 동작합니다(앱 전용 내장 브라우저는 Google이 로그인을 막습니다).

```bash
node desktop/make-icon.mjs          # 로고 → desktop/logo.ico (아이콘을 바꿀 때만)
pwsh -File desktop/build.ps1        # 바탕 화면에 'Logic Note.exe' 생성
```

## 기능

- **캔버스**: 사각형·둥근 사각형·원·마름모·평행사변형·육각형 상자. 상자 테두리를 두 번 누르면 연결점이 커서를 따라 테두리 위를 움직이고, 한 번 더 누르면 그 자리에 놓입니다(모서리·변 가운데에는 자석처럼 붙고, 많이 벗어나면 취소, 점을 오른쪽 클릭하면 삭제). 그 점을 끌어 다른 상자와 연결하고, 빈 곳에 놓으면 이어지는 상자가 생깁니다.
- **집합 (상자 안의 상자)**: 상자를 다른 상자 위로 끌어다 놓으면 그 안에 들어갑니다(들어갈 상자가 주황 점선으로 표시됨). 여러 상자를 골라 **Ctrl+G**(⋯ › 집합으로 묶기)로 한꺼번에 감쌀 수도 있습니다. **많이 감쌀수록 테두리가 두꺼워져** 포함 방향이 보입니다. 집합 안 빈 곳을 두 번 누르면 그 안에 새 상자가 생깁니다.
  - 바깥 상자는 **틀**입니다. 안쪽 상자는 틀 안에서 자유롭게 옮길 수 있고, 틀에 걸쳐 놓으면 틀이 그만큼 늘어납니다(저절로 줄지는 않음). 틀 밖으로 완전히 끌어내야 빠집니다. 틀 크기는 손잡이로 바꾸고, ⋯ › 크기 자동 맞춤을 누르면 안쪽에 딱 맞게 줄어듭니다.
  - **넣고 뺄 때 움직임**: 틀은 예전 크기에서 새 크기로 부드럽게 늘고 줄며, 들어가거나 나온 상자는 살짝 튀며 자리 잡습니다. **다른 상자에 넣기**는 상자들이 대상 안 빈 곳으로 미끄러져 들어가고, **집합에서 꺼내기**(Ctrl+Shift+G)는 틀 오른쪽으로 비켜 나옵니다.
- **연결선**: 직선(기본)/곡선/꺾은선, 화살표/양방향/선만, 점선, 색, 두께, 라벨(선을 두 번 누르기), 관계 기호 **= ≠ ≈**.
- **기본 모양**: 새 상자의 도형·채우기·테두리 색, 새 선의 모양·끝·색·두께를 정해 둡니다. **설정**에서 모든 노트용을, 편집기 ⋮ › 기본 모양에서 **이 노트만** 따로 정할 수 있습니다.
- **상자 내용**: 제목과 설명을 따로 씁니다. 이미지·영상(파일, 붙여넣기, 끌어다 놓기), 링크 미리보기, YouTube 재생 카드.
- **상자 크기**: 기본은 글에 맞춰 자동. 상자 하나를 고르면 모서리·변을 끌어 크기를 직접 정할 수 있고, 도구 막대의 **크기** 버튼에 폭·높이를 숫자로 넣을 수도 있습니다(비우면 그쪽은 자동). 글이 정한 크기보다 많으면 상자가 그만큼 커집니다. ⋯ › 크기 자동 맞춤으로 되돌립니다.
- **메모지**: 도구 막대의 메모지 버튼(또는 빈 곳 오른쪽 클릭)으로 **메모지**(무지)와 **줄 메모지**를 붙입니다. 접힌 모서리가 있는 종이에 왼쪽 위부터 쓰고, 줄 메모지는 글줄이 줄에 맞습니다. 색·크기를 바꿀 수 있고 선으로 이을 수도 있습니다.
- **오른쪽 클릭**: 빈 곳을 **오른쪽 버튼으로 끌면** 여러 상자를 한꺼번에 고르고, 놓으면 메뉴가 뜹니다. 복사·잘라내기·복제·삭제, **다른 상자에 넣기**(메뉴를 고른 뒤 넣을 상자를 누름), 집합으로 묶기·꺼내기. 상자·선·빈 곳을 오른쪽 클릭해도 각각 맞는 메뉴가 나옵니다(터치는 길게 누르기).
- **A4 용지**: 노트를 무한 캔버스 대신 **A4 세로/가로** 종이로 쓸 수 있습니다(빈 노트 가운데의 선택 버튼, 편집기 ⋮ 메뉴, 또는 설정 › 새 노트 용지). 종이는 위에서 아래로 이어지고, 맨 아래 **페이지 추가**로 늘립니다. 아래쪽 `1 / 3` 표시나 상단의 페이지 버튼을 누르면 **페이지 정렬** 창이 열려 썸네일을 끌어 순서를 바꾸고(터치는 길게 눌러서), 페이지를 복제·삭제·추가하고, 누르면 그 페이지로 갑니다. 상자는 놓인 페이지에 속해 페이지와 함께 움직이며, 종이 밖에 놓으면 종이 안으로 돌아옵니다. 무한 캔버스 노트를 A4로 바꾸면 내용이 첫 페이지부터 놓입니다.
  - **페이지 넘기기**: 마우스 휠을 굴리면 페이지 안을 내려가다 끝에서 다음 페이지로 미끄러지듯 넘어갑니다(올리면 이전 페이지). PageUp/PageDown, 아래쪽 ‹ › 버튼도 같습니다. Ctrl+휠(또는 두 손가락)은 확대·축소입니다. 손으로 밀다 놓으면 가까운 페이지에 맞춰 섭니다.
  - **다음 페이지 위치**: 페이지 창이나 ⋮ 메뉴에서 **아래로**(기본) 또는 **옆으로** 고릅니다. 바꾸면 각 페이지 내용은 그대로 따라갑니다.
- **서식**: 글꼴(기본·명조·둥근 고딕·손글씨·코드), 크기(목록에서 고르거나 `10p`처럼 직접 입력, 단위 pt), 굵게·기울임·밑줄·취소선, 글자색, 형광펜(색 선택), 정렬, 글머리 기호·번호·체크리스트. 편집 중엔 선택한 글자에만, 편집 중이 아닐 땐 선택한 상자 전체에 적용됩니다.
- **마크다운**: 입력하면 바로 서식이 됩니다(`# 제목`, `- 목록`, `1. 번호`, `**굵게**`, `*기울임*`, `~~취소~~`, `` `코드` ``, `> 인용`, ```` ``` ```` 코드 블록). 마크다운 글을 상자에 붙여넣거나 캔버스에 붙여넣어도 서식으로 바뀝니다.
- **노트별 다크 모드**: 편집기 위쪽의 달/해 버튼으로 이 노트만 다크 모드를 켜고 끕니다(삼성 노트처럼 종이만 바뀌고 앱 화면은 그대로). 바탕색을 정한 노트도 그에 맞춰 어둡거나 밝게 바뀝니다.
- **색 고르기**: 주요 색과 최근 사용한 색, **고급 설정**을 누르면 전체 스펙트럼 + HEX 입력.
- **배경**: 상단의 배경 버튼에서 노트마다 **바탕색**(종이 같은 옅은 색, 칠판 같은 짙은 색, 고급 설정으로 아무 색)과 **무늬**(모눈, 넓은 모눈, 그리드(점), 넓은 그리드(점), 줄, 없음)를 고릅니다. 바탕이 어두우면 상자·선·글자 기본색이 저절로 어두운 바탕용으로 바뀝니다. A4 노트에서는 종이 색이 됩니다. **이 배경을 새 노트 기본으로**를 누르면 새 노트에 씁니다. 노트마다 따로 정하고 기본값도 바꿀 수 있습니다.
- **다크 모드**: 시스템/라이트/다크. 무채색(검정·회색·흰색)은 모드가 바뀌면 자동으로 반전되고, 글자가 바탕에 묻히면 읽히는 쪽으로 뒤집힙니다. 유채색은 그대로 둡니다.
- **정리**: 폴더 안에 폴더(트리), 즐겨찾기, 휴지통, 검색, 정렬. 폴더를 누르면 하위 폴더와 노트 미리보기가 카드로 보입니다. 노트 카드를 사이드바 폴더로 끌어다 옮길 수 있습니다.
  - **그룹**: 사이드바 폴더 옆 + › 새 그룹으로 폴더를 묶는 접이식 묶음을 만들고, 폴더를 끌어다 넣습니다(그룹 해제해도 폴더는 그대로).
  - 새 노트를 만들고 아무것도 하지 않은 채 나가면 그 노트는 자동으로 지워집니다.
- **AI 도식 가져오기**: Claude·ChatGPT 등이 그려 준 Mermaid(flowchart·graph·mindmap)나 Graphviz(DOT) 코드를 상자와 연결선으로 바꿔 자동 배치합니다. 모양·색·점선·라벨도 옮겨 옵니다.
  - 캔버스에 AI 답변을 그대로 **붙여넣기(Ctrl+V)** 하거나, `.mmd`/`.dot` 파일을 끌어다 놓거나, 편집기 ⋮ 메뉴·노트 목록 상단의 **가져오기** 버튼을 씁니다.
  - 가져오기 창의 **AI에게 보낼 요청문 복사**로 AI가 바로 가져올 수 있는 형식으로 답하게 할 수 있습니다.
- **내보내기**: 편집기 ⋮ 메뉴 › 내보내기. 노트 전체를 **PNG·SVG 그림**으로 저장하거나 클립보드에 복사하고, 글·코드로 복사·저장합니다.
  - **AI용 개요**: 연결을 따라 펼친 흐름(되먹임·합류는 ↺)과 상자마다의 설명·모양·색을 글로 정리합니다. Claude·ChatGPT에 붙여넣으면 노트의 논리를 가장 정확하게 읽습니다.
  - **Mermaid·Graphviz**: 상자 제목은 굵게 표시해 설명과 구분합니다. Notion·GitHub·Obsidian에서는 그림으로 보이고, Logic Note로 다시 가져오면 제목·설명이 그대로 나뉩니다.
- **움직임**: 노트를 열고 닫을 때, 메뉴·창이 뜨고 닫힐 때, 노트 카드가 나타나거나 자리를 바꿀 때, 폴더를 접고 펼 때, 도구 막대가 바뀔 때, 새 상자가 생길 때 짧고 부드럽게 움직입니다. 기기의 '동작 줄이기' 설정을 켜면 움직임을 끕니다.
- **언어**: 설정 › 언어에서 자동(기기 언어)·한국어·English. 바꾸면 앱이 다시 열립니다. AI용 개요와 AI 요청문도 그 언어로 나옵니다.
- **실행 취소/다시 실행**, 복사/붙여넣기, 백업 내보내기·가져오기(JSON).

## Google Drive 동기화 설정

동기화하면 **내 드라이브 › Logic Note** 폴더 아래에 앱의 폴더 구조가 그대로 만들어지고, 노트는 하나씩 `제목.lnote` 파일로 저장됩니다. 이미지·영상은 `Logic Note/.media`에 들어갑니다. 권한은 `drive.file`이라 **이 앱이 만든 파일에만** 접근합니다.

처음 한 번만 Google Cloud에서 클라이언트 ID를 만들면 됩니다.

1. <https://console.cloud.google.com> 에서 새 프로젝트를 만듭니다.
2. **API 및 서비스 › 라이브러리**에서 **Google Drive API**를 사용 설정합니다.
3. **OAuth 동의 화면**: 사용자 유형 *외부*, 앱 이름 입력, **테스트 사용자**에 본인 Gmail을 추가합니다.
4. **사용자 인증 정보 › 사용자 인증 정보 만들기 › OAuth 클라이언트 ID** → 유형 *웹 애플리케이션*.
   **승인된 JavaScript 원본**에 앱을 여는 주소를 모두 넣습니다. 예: `http://localhost:5173`, `https://내아이디.github.io`
5. 만들어진 클라이언트 ID(`….apps.googleusercontent.com`)를 저장소 변수 `GOOGLE_CLIENT_ID`에 넣고 다시 배포하거나, 앱의 **설정 › Google Drive 동기화**에 직접 붙여넣은 뒤 **Google 계정 연결**을 누릅니다.

다른 기기에서도 같은 주소로 열고, 같은 클라이언트 ID로 연결하면 같은 노트가 보입니다.

- 수정하면 몇 초 뒤, 그리고 3분마다·앱으로 돌아올 때 자동으로 동기화합니다. 상단의 구름 아이콘을 누르면 바로 동기화합니다.
- Google 로그인 토큰은 1시간마다 만료됩니다. 구름 아이콘에 주황 표시가 뜨면 눌러서 다시 로그인하세요(보통 클릭 한 번).
- 두 기기에서 같은 노트를 동기화 전에 각각 고쳤다면, 최신 쪽을 남기고 다른 쪽은 `(다른 기기)`/`(이 기기)` 사본으로 보존합니다.

## 데이터

노트는 브라우저의 IndexedDB에 저장됩니다(기기마다 따로). 동기화를 안 쓴다면 **설정 › 백업**으로 가끔 내보내 두세요. 링크 미리보기는 microlink.io로 링크 주소를 보내 가져오며, 설정에서 끌 수 있습니다.
